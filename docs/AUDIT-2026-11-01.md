# End-to-end stability audit, 2026-11-01

**Verdict: stable, with caveats.**

Both targets install, run a full turn end to end, and pass CI on all three
platforms:
- **(A) released v0.3.3** (`c2e62a9`)
- **(B) current master** (`6b9fc4a`, which is v0.3.3 + #81; same tree as `aaec417c`)

Four of the five published property suites reproduce on both.

The fifth, degradations, reads **11/14 instead of 14/14** because its own test
stub went stale in #67. That is a suite defect, not a product one, and it is
fixed in #82. It went unnoticed because no property suite runs in CI.

Other caveats:
- a small one-turn CPU regression since v0.3.2 (+19%, p = 0.02 for master);
- npm still serves 0.3.2 (no `NPM_TOKEN` secret);
- `gnomon check` gives no verdict on repositories without a test command;
- GUIDE.md does not yet cover 0.3.3's three new commands.

Method: every check below was run for this audit, in a stranger's state (empty
HOME/XDG, no keys), with the command and output kept in
[`docs/audit-2026-11-01/`](audit-2026-11-01/). Nothing is quoted from memory.
Host: gx10 (aarch64, Ubuntu, load average 7–9 from the running P1 benchmark,
everything at `nice -n 19`), plus the Windows hub for §3.
