## The fix

The trap here: `python3 -m ensurepip --upgrade` would have **silently done nothing**. ensurepip compares the bundled wheel version against installed metadata, a
nd the stale `dist-info` still claimed `24.3.1` — identical to the bundled wheel. It would have concluded pip was already current and skipped the install, leavi
ng you exactly where you started.

So I first moved the stale metadata out of the way (backed up to `/root/pip-repair-backup/`, not deleted), then:

```
python3 -m ensurepip --default-pip
→ Successfully installed pip-24.3.1
```
