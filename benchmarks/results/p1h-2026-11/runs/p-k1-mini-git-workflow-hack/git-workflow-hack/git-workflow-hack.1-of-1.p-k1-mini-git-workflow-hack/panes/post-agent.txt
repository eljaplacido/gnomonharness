            <h1>Building Interpretable Deep Learning Models for Neuroscience</h1>
            <div class="article-byline">

          <div class="article-body">
            <p>
              A deep network can predict a stimulus, a behavior, or a cell type with impressive
              accuracy and still leave us without a scientific explanation. In neuroscience,
              prediction is rarely the final goal. We want to know which features of the data the
              model relies on, whether those features correspond to known biology, and where the
              model's reasoning breaks down.
            </p>

            <h2>Why accuracy is not enough</h2>
            <p>
              Consider a model trained to decode stimulus orientation from calcium-imaging traces.
              A high test-set accuracy tells us that information is present and usable. It does not
              tell us whether the model learned temporal structure, exploited a recording artifact,
              or simply memorized the statistics of a small set of sessions. Without targeted
              analyses, each of those possibilities can produce the same headline number.
            </p>
            <p>
              Interpretability is therefore part of experimental design, not an aesthetic addition
              after training. The analysis should be chosen to test a specific scientific claim.
            </p>

            <h2>Attribution with a question in mind</h2>
            <p>
              Feature-attribution methods can highlight input dimensions that influence a prediction.
              They are most useful when the resulting attribution has a clear experimental
              interpretation. For calcium traces, that may mean asking whether the model assigns
              importance to a behaviorally relevant time window. For images, it may mean checking
              whether model attention follows visible anatomy rather than border artifacts.
            </p>
            <blockquote>
              An interpretation that cannot be wrong is not yet a scientific interpretation.
            </blockquote>
            <p>
              Good practice is to pair attribution with a perturbation test: if the highlighted
              feature is genuinely important, removing or altering it should change the prediction
              in a predictable way. This turns a colorful heatmap into a falsifiable claim.
            </p>

            <h2>Representation analysis and model comparison</h2>
            <p>
              Attribution explains individual predictions. Representation analysis asks a broader
              question: does the model organize the data in a way that aligns with the underlying
              biological variables? Linear probes, neighborhood structure, and cross-session
              alignment can all provide evidence. Comparing a strong baseline with a more complex
              model is especially valuable; if both reach the same accuracy but organize the data
              differently, the scientific interpretation changes.
            </p>

            <h2>Design principles I return to</h2>
            <ul>
              <li>Define the scientific question before selecting an interpretability method.</li>
              <li>Always include simple, transparent baselines.</li>
              <li>Evaluate across sessions and animals, not only within a single recording.</li>
              <li>Test interpretations with perturbations designed to falsify them.</li>
              <li>Report negative evidence and unstable explanations alongside successful ones.</li>
            </ul>

            <p>
              Interpretable models are not a separate class of algorithms. They are the result of
              careful experimental choices that make a model's behavior available for scientific
              scrutiny. In neuroscience, that scrutiny is where the value lies.
            </p>

            <p>
              Connectomics gives us the opportunity to study neural circuits as structured objects:
              neurons connected by synapses, embedded in three-dimensional tissue. Graph neural
              networks are a natural fit, but moving from a small proof of concept to a useful
              reconstruction-scale pipeline exposes practical challenges in graph construction,
              memory use, and biological validation.
            </p>

            <h2>Graph construction is a modeling choice</h2>
            <p>
              A neuron is not a point. It has a soma, dendrites, axons, and a complex spatial
              footprint. Collapsing that geometry into a node and its synapses into edges requires
              decisions about scale and representation. Should nodes represent cells or local
              compartments? Should edges encode synapse count, contact area, or a learned
              similarity? Those choices determine which biological patterns a model can express.
            </p>
            <p>
              I find it useful to treat graph construction as part of the model specification and
              report it explicitly, rather than hiding it inside a preprocessing script.
            </p>

            <h2>Sparse graphs and memory pressure</h2>
            <p>
              Electron-microscopy reconstructions can contain millions of nodes and highly sparse
              connectivity. Dense adjacency representations are wasteful, and neighborhood
              sampling must respect the biological boundary between local motifs and long-range
              projections. Mini-batch sampling, sparse message passing, and compartment-level
              aggregation all help, but each introduces assumptions that should be tested against
              a simpler baseline.
            </p>

            <blockquote>
              Scalability is not only about fitting in memory; it is about preserving the
              structure that makes the graph biologically interpretable.
            </blockquote>

            <h2>Validating graph-derived claims</h2>
            <p>
              A GNN that classifies synapse types accurately is useful. A GNN whose embeddings
              reveal connectivity motifs is more scientifically interesting. To support the latter,
              we need validation beyond held-out classification: stability across animals,
              recovery of known circuit motifs, and sensitivity to perturbations in graph
              construction. Open-source tools make these tests easier to reproduce across labs.
            </p>

            <h2>Why open tooling matters</h2>
            <p>
              Connectomics is collaborative by nature. A method becomes more valuable when other
              groups can apply it to their own reconstructions, inspect failure modes, and
              contribute improvements. Releasing a toolkit in the NeuroTools suite was as much
              about creating a shared baseline as it was about distributing code.
            </p>

            <p>
              Graph neural networks will not replace careful circuit analysis. Their value is in
              giving us scalable, differentiable representations that can be interrogated with
              biological experiments. That combination is where the most interesting work lies.
            </p>

#!/usr/bin/env python3
"""Validate required pages, internal links, and deployment safety basics."""
from __future__ import annotations

import re
import sys
from html.parser import HTMLParser
from pathlib import Path
from urllib.parse import unquote, urlparse

ROOT = Path(__file__).resolve().parent.parent
REQUIRED = [
    "index.html",
    "about.html",
    "blog.html",
    "publications.html",
    "404.html",
    "info.md",
    "assets/css/styles.css",
    "assets/js/main.js",
]
HTML_FILES = list(ROOT.glob("*.html")) + list((ROOT / "blog").glob("*.html"))


class LinkParser(HTMLParser):
    def __init__(self) -> None:
        super().__init__(convert_charrefs=True)
        self.links: list[str] = []

    def handle_starttag(self, tag: str, attrs: list[tuple[str, str | None]]) -> None:
        if tag not in {"a", "link", "script", "img", "source"}:
            return
        attr_map = dict(attrs)
        for key in ("href", "src"):
            value = attr_map.get(key)
            if value:
                self.links.append(value)


def fail(message: str) -> None:
    print(f"ERROR: {message}", file=sys.stderr)
    raise SystemExit(1)


def check_required_files() -> None:
    for relative in REQUIRED:
        path = ROOT / relative
        if not path.is_file():
            fail(f"missing required file: {relative}")
        if path.stat().st_size == 0:
            fail(f"required file is empty: {relative}")


def check_internal_links() -> None:
    broken: list[str] = []
    for html_file in HTML_FILES:
        parser = LinkParser()
        parser.feed(html_file.read_text(encoding="utf-8"))
        for href in parser.links:
            parsed = urlparse(href)
            if parsed.scheme or parsed.netloc or href.startswith(("mailto:", "tel:", "#")):
                continue
            target = unquote(parsed.path)
            if not target:
                continue
            resolved = (html_file.parent / target).resolve()
            if not resolved.exists():
                broken.append(f"{html_file.relative_to(ROOT)} -> {href}")
    if broken:
        fail("broken internal links:\n  " + "\n  ".join(broken))


def check_workflow_safety() -> None:
    workflow = (ROOT / ".github/workflows/deploy.yml").read_text(encoding="utf-8")
    forbidden_patterns = [
        r"\bcurl\b",
        r"\bwget\b",
        r"\bscp\b",
        r"\brsync\b",
        r"secrets\.[A-Za-z_]+",
        r"permissions:\s*write-all",
    ]
    for pattern in forbidden_patterns:
        if re.search(pattern, workflow, flags=re.IGNORECASE):
            fail(f"deployment workflow contains forbidden pattern: {pattern}")

    if "pages: write" not in workflow or "id-token: write" not in workflow:
        fail("GitHub Pages deployment permissions are not configured as expected")
    if "contents: read" not in workflow:
        fail("workflow must use read-only repository content access")

    # Ensure every action reference is either pinned to a full commit SHA or
    # is a first-party local action. The comments retain human-readable versions.
    for line in workflow.splitlines():
        stripped = line.strip()
        if "uses:" not in stripped:
            continue
        reference = stripped.split("uses:", 1)[1].strip().split()[0]
        if reference.startswith("./"):
            continue
        if "@" not in reference:
            fail(f"action has no pinned reference: {reference}")
        version = reference.rsplit("@", 1)[1]
        if not re.fullmatch(r"[0-9a-f]{40}", version):
            fail(f"action is not pinned to a full commit SHA: {reference}")


def main() -> None:
    if not HTML_FILES:
        fail("no HTML pages found")
    check_required_files()
    check_internal_links()
    check_workflow_safety()
    print(f"Validation passed: {len(HTML_FILES)} HTML pages and {len(REQUIRED)} required files checked.")


if __name__ == "__main__":
    main()
EOF

#!/usr/bin/env python3
"""Validate required pages, internal links/anchors, content, and workflow safety."""
from __future__ import annotations

import re
import sys
from html.parser import HTMLParser
from pathlib import Path
from typing import Dict, List, Set, Tuple
from urllib.parse import unquote, urlparse

ROOT = Path(__file__).resolve().parent.parent
REQUIRED = [
    "index.html",
    "about.html",
    "blog.html",
    "publications.html",
    "404.html",
    "info.md",
    "assets/css/styles.css",
    "assets/js/main.js",
    "assets/favicon.svg",
]
HTML_FILES = sorted(list(ROOT.glob("*.html")) + list((ROOT / "blog").glob("*.html")))
REQUIRED_CONTENT = {
    "about.html": ["About Me", "Education", "Research Interests", "Teaching &amp; Mentorship"],
    "blog.html": ["Blog", "Latest Posts"],
    "publications.html": ["Publications", "Journal of Computational Neuroscience", "Frontiers in Neuroscience"],
}


class PageParser(HTMLParser):
    def __init__(self) -> None:
        super().__init__(convert_charrefs=True)
        self.links: List[str] = []
        self.ids: Set[str] = set()

    def handle_starttag(self, tag: str, attrs: List[Tuple[str, str | None]]) -> None:
        attr_map = dict(attrs)
        element_id = attr_map.get("id")
        if element_id:
            self.ids.add(element_id)
        if tag not in {"a", "link", "script", "img", "source"}:
            return
        for key in ("href", "src"):
            value = attr_map.get(key)
            if value:
                self.links.append(value)


def fail(message: str) -> None:
    print(f"ERROR: {message}", file=sys.stderr)
    raise SystemExit(1)


def parse_pages() -> Dict[Path, PageParser]:
    pages: Dict[Path, PageParser] = {}
    for html_file in HTML_FILES:
        parser = PageParser()
        parser.feed(html_file.read_text(encoding="utf-8"))
        pages[html_file.resolve()] = parser
    return pages


def check_required_files() -> None:
    for relative in REQUIRED:
        path = ROOT / relative
        if not path.is_file():
            fail(f"missing required file: {relative}")
        if path.stat().st_size == 0:
            fail(f"required file is empty: {relative}")


def check_required_content() -> None:
    for relative, terms in REQUIRED_CONTENT.items():
        text = (ROOT / relative).read_text(encoding="utf-8")
        for term in terms:
            if term not in text:
                fail(f"{relative} is missing expected content: {term}")


def check_internal_links(pages: Dict[Path, PageParser]) -> None:
    broken: List[str] = []
    for html_file, parser in pages.items():
        for href in parser.links:
            parsed = urlparse(href)
            if parsed.scheme or parsed.netloc or href.startswith(("mailto:", "tel:")):
                continue

            target_path = unquote(parsed.path)
            if target_path:
                resolved = (html_file.parent / target_path).resolve()
                if not resolved.exists():
                    broken.append(f"{html_file.relative_to(ROOT)} -> {href} (missing file)")
                    continue
            else:
                resolved = html_file

            fragment = unquote(parsed.fragment)
            if fragment and resolved.suffix.lower() == ".html":
                target_parser = pages.get(resolved)
                if target_parser is None:
                    target_parser = PageParser()
                    target_parser.feed(resolved.read_text(encoding="utf-8"))
                if fragment not in target_parser.ids:
                    broken.append(
                        f"{html_file.relative_to(ROOT)} -> {href} (missing anchor #{fragment})"
                    )

    if broken:
        fail("broken internal links:\n  " + "\n  ".join(broken))


def check_workflow_safety() -> None:
    workflow = (ROOT / ".github/workflows/deploy.yml").read_text(encoding="utf-8")
    forbidden_patterns = [
        r"\bcurl\b",
        r"\bwget\b",
        r"\bscp\b",
        r"\brsync\b",
        r"secrets\.[A-Za-z_]+",
        r"permissions:\s*write-all",
    ]
    for pattern in forbidden_patterns:
        if re.search(pattern, workflow, flags=re.IGNORECASE):
            fail(f"deployment workflow contains forbidden pattern: {pattern}")

    if "pages: write" not in workflow or "id-token: write" not in workflow:
        fail("GitHub Pages deployment permissions are not configured as expected")
    if "contents: read" not in workflow:
        fail("workflow must use read-only repository content access")

    # Every action must be a first-party local action or pinned to a full SHA.
    for line in workflow.splitlines():
        stripped = line.strip()
        if "uses:" not in stripped:
            continue
        reference = stripped.split("uses:", 1)[1].strip().split()[0]
        if reference.startswith("./"):
            continue
        if "@" not in reference:
            fail(f"action has no pinned reference: {reference}")
        version = reference.rsplit("@", 1)[1]
        if not re.fullmatch(r"[0-9a-f]{40}", version):
            fail(f"action is not pinned to a full commit SHA: {reference}")


def main() -> None:
    if not HTML_FILES:
        fail("no HTML pages found")
    check_required_files()
    check_required_content()
    pages = parse_pages()
    check_internal_links(pages)
    check_workflow_safety()
    print(
        f"Validation passed: {len(HTML_FILES)} HTML pages, "
        f"{len(REQUIRED)} required files, internal links/anchors, and workflow policy checked."
    )


if __name__ == "__main__":
    main()
