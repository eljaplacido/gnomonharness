
Worth clearing out of the way: this is *not* PEP 668. The `EXTERNALLY-MANAGED` file on this box belongs to Debian's Python 3.11 at `/usr/lib/python3.11/`; your
`python3` is the official `python:3.13` image at `/usr/local/bin/python3`, which has no such file. No venv is needed to install system-wide here — the install w
as root-owned and you are root.

**The fix:** `python3 -m ensurepip --upgrade` does *not* repair this — it sees the surviving dist-info, decides pip is "already satisfied", and leaves you broke
n. The working route was unpacking the bundled wheel over the top:

```

python3 -m zipfile -e /usr/local/lib/python3.13/ensurepip/_bundled/pip-24.3.1-py3-none-any.whl .
```
